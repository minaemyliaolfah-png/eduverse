EDUVERSE · PANDUAN GURU

Dari game solo
ke ruang bersama.

Satu proyek Firebase dipakai oleh seluruh siswa. Lakukan penyiapan sekali sebagai pemilik game. Siswa cukup membuka game, membuat akun, dan memasukkan kode ruang.

← Kembali ke game

1. Buat proyek Firebase

  1. Buka Firebase Console dan masuk menggunakan akun Google Anda.
  2. Buat proyek baru, misalnya EDUVERSE Sekolah. Analytics tidak diperlukan oleh game ini.
  3. Mulai dengan paket Spark jika mencukupi. Proyek ini tidak memerlukan Cloud Functions atau kartu pembayaran untuk fitur yang dibuat. Kuota tetap berlaku.
  4. Di Project settings → General, tambahkan aplikasi Web (</>). Hosting tetap GitHub Pages. Simpan objek firebaseConfig yang ditampilkan.

2. Aktifkan tiga layanan

  1. Authentication → Get started → Sign-in method → aktifkan Email/Password. Jangan aktifkan metode lain hanya untuk panduan ini.
  2. Authentication → Settings → Authorized domains: tambahkan domain GitHub Pages Anda, misalnya namaguru.github.io, tanpa https dan tanpa nama repository. Untuk uji komputer tambahkan localhost bila dibutuhkan.
  3. Firestore Database → Create database → pilih Standard/default database dan lokasi yang sesuai. Mulai dengan aturan tertutup/production.
  4. Realtime Database → Create database → pilih lokasi → mulai dengan aturan tertutup/locked. Salin alamat database yang ditampilkan; inilah databaseURL.

Konfigurasi aplikasi web bisa tidak memuat databaseURL jika disalin sebelum Realtime Database dibuat. Tambahkan alamat tersebut di bawah.

3. Pasang aturan akses

Aturan bawaan yang tertutup akan menolak game sampai Anda memasang aturan khusus ini. Jangan menggantinya dengan izin baca/tulis untuk semua orang.

  1. Di Realtime Database → Rules, ganti isi editor dengan seluruh isi database.rules.json, lalu Publish.
  2. Di Firestore Database → Rules, ganti isi editor dengan seluruh isi firestore.rules, lalu Publish.

Jika proyek sudah menyimpan aplikasi lain, pakai proyek Firebase terpisah untuk EDUVERSE agar tidak menimpa kebijakan akses aplikasi tersebut.

4. Buat berkas konfigurasi game

Tempel objek konfigurasi web yang diberikan Firebase. Halaman ini hanya memproses teks di browser dan membuat berkas unduhan; tidak menjalankan kode yang ditempel.

Konfigurasi web Firebase memang dipakai di frontend. Jangan tempel service-account key, private key, atau password. Perlindungan data berasal dari Authentication dan Security Rules.


5. Unggah dan mulai multiplayer
  1. Simpan hasil unduhan sebagai firebase/config.json, menggantikan berkas kosong di paket game.
  2. Unggah seluruh isi paket terbaru ke GitHub, termasuk folder firebase, js, data, dan vendor. Jika memakai ZIP, ekstrak dulu.
  3. Tunggu deployment GitHub Pages selesai, kemudian buka tautan game.
  4. Isi nama, pilih karakter dan tempat. Buka tombol Teman di kanan atas.
  5. Daftar atau masuk akun → Buat ruang → bagikan kode 8 karakter.
  6. Teman membuka game di perangkatnya, masuk dengan akun berbeda, lalu memilih Gabung ruang dengan kode yang sama.
  7. Tutup panel Teman untuk menjelajah. Pemain lain memakai label PEMAIN; pemandu komputer memakai label NPC.


6. Uji dua akun sebelum dipakai di kelas
Gunakan dua HP atau dua profil browser berbeda, bukan sekadar dua tab dengan akun yang sama.
  1. Pastikan kedua akun melihat satu sama lain dalam ruang yang sama.
  2. Gerakkan pemain A; periksa gerak terlihat di B, lalu lakukan sebaliknya.
  3. Coba melompat, berpindah tempat, emote, dan pesan cepat.
  4. Putuskan koneksi B. Avatar B harus hilang setelah server mendeteksi disconnect. Sambungkan kembali; avatar harus muncul lagi.
  5. Uji Bisukan/Keluarkan dari akun pemilik ruang.
  6. Keluar akun, masuk kembali, dan periksa progres latihan.
Emulator lokal sudah dipakai untuk pengujian pengembangan. Pengujian di proyek Firebase Anda tetap diperlukan setelah konfigurasi dan rules dipasang.


Kuota dan batas fitur
Per 27 Oktober 2026, Spark Realtime Database mencantumkan 100 koneksi bersamaan, penyimpanan 1 GB, dan unduhan 10 GB/bulan. Batas EDUVERSE adalah 24 anggota per ruang; ini bukan janji bahwa 24 pemain selalu lancar atau pemakaian selalu gratis. Pantau halaman Usage, mulai dengan kelompok kecil, dan jangan mengaktifkan Blaze tanpa memahami biaya. Harga dan kuota resmi.
Pemilik ruang mengatur anggota ruang, bukan administrator penilaian sekolah. Komunikasi berupa pesan cepat pilihan dan emote. Progres yang disimpan adalah latihan yang dilaporkan browser, bukan nilai resmi tahan manipulasi. Panel administrasi materi/penilaian resmi belum menjadi bagian paket ini.


Jika koneksi belum berhasil
  • Firebase belum dihubungkan: pastikan config.json berada di folder firebase dan tidak kosong.
  • Permission denied: pastikan kedua rules dipublikasikan di proyek yang sama; jangan membuka seluruh database.
  • Akun gagal dibuat: aktifkan Email/Password, cek email dan sandi minimal 8 karakter.
  • Teman tidak terlihat: cek kode ruang, akun berbeda, status Online, dan lokasi pemain. Gunakan Dunia → Huma Betang pada kedua perangkat.
  • Ruang penuh: pemilik dapat mengeluarkan anggota offline yang tidak dipakai atau membuat ruang baru.
  • Keluar/diblokir: hanya pemilik ruang atau pengelola Firebase dapat membatalkan blokir; jangan menonaktifkan rules.
